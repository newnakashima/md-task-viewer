## 概要

タスクの追加や編集、並び替え、コマンド実行など、書き込み系の操作をできないモードでビルドできるようにする。
サーバー側のAPIを叩かないようにする。

## 目的

現在はローカルマシン上でサーバーを起動させて使用する前提となっているが、外出先などからスマートフォンで公開Web経由でタスクを確認したいときがある。

そのような用途向けに、Read only モードでビルドできるようにして、その静的コンテンツを任意のサーバーでホストできるようにする。

公開Web経由のアクセスではタスクの確認のみが可能。

## 認証をどうするか

- 特定の鍵でタスクの内容を暗号化してホストする
  - 鍵は生成スクリプトを用意し、標準出力に出力する
  - 環境変数に追加することを推奨するメッセージを表示する。環境変数に追加されていれば、ビルド時に自動でその鍵が使われるようにする
- 鍵はビルド時に指定して、タスク内容を暗号化する。鍵自体は絶対にホストしない
- 公開Web経由でアクセス時にキー入力モーダルを表示。入力されたキーで復号して表示
- 鍵を設定しなかった場合は、暗号化なしで公開される。ビルド時に Warning を出す。

## 想定ホスティング環境

- 静的ファイルをホストできるならどんな環境でもOK
  - S3
  - Apache、Nginx などの Web サーバー
  - Netlify
  - Cloudflare
- main にマージされたら自動で再デプロイする方法のサンプルコードをドキュメントに記載する
